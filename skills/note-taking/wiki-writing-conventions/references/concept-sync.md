# 概念同步（改完笔记/讲完数学之后的硬性收尾）

用户 2026-10-19 指出：代数III 概念页比讲解落后很多，`群论学习路径` 停在 9 月 8 日。
根因不是遗忘，是规则缺口——旧技能只写了「答疑即沉淀」，没写「讲义入库后要同步概念页」，
也没给地图类文件定义义务。这份文件补的就是那个缺口。

## 1. 什么时候触发

任一条成立就触发：

- 讲义/手写扫描件入库、笔记被拆章或改写；
- 讲解、答疑、复习（含陪练中给出的关键结论）；
- 用户修正了某个概念的理解或记号；
- 新建/删除/改名了任何概念页。

## 2. 同一轮内必须走完的四步

1. **列概念**：这一章/这次问答涉及哪些概念？（先列名，再决定更新还是新建）
2. **落概念页**：已有页就补（bump `updated`），没有就建（frontmatter 六字段齐全，≥2 出链）。
3. **同步地图**：该课的 `_索引.md`、`学习路径`、`概念页索引` 里必须出现新页或改过的页；
   描述与页面内容不一致时，改描述（不是只加链接）。
4. **log + commit**：`log.md` 追加一条，`git add` 只加目标文件，commit 后再 push。

**不要**问「要不要整理进 wiki」；**不要**把概念页写成讲义总结（见 SKILL 正文第 2 条）。

## 3. 地图类文件的两类职责

登记表：`references/concept-map-registry.json`（唯一名单，25 项）。

| duty | 含义 | 检查方式 |
|---|---|---|
| `concept-index` | 承担概念清单：学习路径、概念页索引 | 陈旧 + 孤儿页（漏链） |
| `course-index` | 学科/课程索引 `_索引.md` | 只查陈旧 |
| `notes-entry` | 讲义章节入口 `00-总览.md` | 只查存在 |

判断标准：**这个文件被删掉，概念页还有别的地方能找全吗？** 能 → notes-entry；不能 → concept-index。
笔记的 `00-总览.md` 不要按文件名一刀切：逐份读后标定，只有真的承担概念清单职责的才同步。
新建任何 `*路径*.md`、`*索引*.md`、`*总览*.md` 都要先登记；文件删除/改名要同步删行。

## 4. 检查命令

```
python3 ~/.hermes/skills/note-taking/wiki-writing-conventions/scripts/check_concept_sync.py
python3 ~/.hermes/skills/note-taking/wiki-writing-conventions/scripts/check_concept_sync.py --verbose
```

三项检查：

1. **陈旧**：地图文件 frontmatter 的 `updated` 早于它 `covers` 目录里概念页的最大 `updated`；
2. **未登记/缺失**：磁盘上匹配 `学习路径|概念页索引|_索引|00-总览` 的文件不在 registry 里，或 registry 指向的文件不存在；
3. **孤儿**：`concept-index` 文件里没有链到某个概念页。

退出码 0 才算收尾完成；非 0 就回到第 2 步。

脚本把地图类文件本身从「概念页」里排除（按文件名模式 `学习路径|概念页索引|_索引|00-总览`）。
不排除的话，扁平目录（如 `物理/理论力学/`，学习路径与概念页平铺）会把学习路径自己算成孤儿页，报一堆假问题。

脚本另有一项**不计入退出码的提示**：概念目录内跨课重名（「一概念一文件」的存量违例，合并要人工判断内容取舍，不能脚本硬删）。

## 5. 最容易漏的三处

- 新建概念页后只改了 `_索引`，忘了改 `学习路径`（两者职责不同，前者是目录，后者是因果链）。
- 改了概念页内容但没 bump `updated`，脚本就看不见这次变更（陈旧检查靠它）。
- 改了地图内容但没 bump 地图自己的 `updated`，下次仍会被报陈旧。

## 6. 跨课程概念

同一概念只在最早那门课有一页（`代数I/概念/半直积` 这类）。后来的课要讲，就补进同一页并
从新课的地图里用完整路径链接（`[[代数I/概念/半直积]]`），**不要在新课复制同名页**——
复制会让裸链 `[[半直积]]` 变二义。
