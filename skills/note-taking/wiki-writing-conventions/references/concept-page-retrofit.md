# 既有概念页的规范整理(retrofit / audit)工作流

2026-09-14 实战:用户说「理论力学里面的所有概念都这样重新理一下, 之前有些写的不太规范」。
这是一类**反复出现**的任务(每次课程推进或写作规范演进后都会需要),不是一次性任务。

## 触发

- 用户说「重新理一下」「之前写得不太规范」「按这个格式改一遍」
- 新定了一条写作规范,需要回扫历史页面
- 某页体量异常(>4 KB 或多概念混杂)被用户点名

## 步骤

1. **先提交用户自己的未提交改动**(若他要求)。2026-09-14 用户原话「**我的改动你直接一起提交掉就好**」
   ——这是**常设授权**:`git status` 里看到的用户遗留改动(如把某页从 `概念\` 移进 `笔记\`)直接
   `git add -A <目录>` + 提交,不要留着混进自己后续的 commit。提交信息写清是什么改动。
   **但仍要单独成一个 commit**,别和你的整理混在一起。

2. **全量读入待整理的页面**。用 `read_file` 逐页读完(不是抽检)——不读完就会漏掉缺陷。
   记录每页的字节数和章节结构。

3. **建缺陷清单**。本会话在 4 个历史页面上实际发现的缺陷类型(可直接作为检查表):

| 缺陷 | 实例 | 处置 |
|---|---|---|
| **小节编号重复** | `伽利略群.md` 有两个 `### 3.`、两个 `### 5.`(后期插入未重编号) | 连续重编号;或拆页 |
| **重复段落** | `牛顿决定性原理….md` 第 153–156 行是 111–114 行的逐字重复(裸列表挂在末尾) | 删重复 |
| **一页塞多个独立概念** | `伽利略群.md` 15 KB,内含「时间平移⇒方程自治」「系统/外部/自治化」两大独立主题 | 拆成独立页,原页加链接 |
| **作业题痕迹** | `速度图与圆锥曲线轨道.md` 满是「(b) 彗星」「(c)」「(d)」「作业第 4 题」 | 改成概念表述(见 SKILL.md「概念页 ≠ 题解汇编」) |
| **非概念内容混入** | `牛顿决定性原理….md` 后半是科学哲学漫谈(「物理原理能否作基础」「牛顿的朴素微积分」) | 删;不属于力学概念 |
| **「相关概念」当正文小节** | `仿射空间.md` 用 `### 6. 相关概念` | 升为顶层 `## 相关概念` |
| **空 frontmatter 字段** | 多页有 `sources: []` | 删掉空字段 |
| **断链** | `仿射空间.md` 有 `[[群作用]]`,但该页在代数目录 | 改纯文字 + 「见代数目录」,不建链 |

4. **统一到同一条规范**(每页都满足):
   - 标题编号**连续、不重复**;顶层只放内容小节 + `## 相关概念`;
   - frontmatter 不留空 `sources`;`updated` 改成本次日期;
   - 页内**不塞第二个独立概念**(判据:小节能独立成页吗?能就拆);
   - **不写作业题号**、题目专属数值、凑题过程;
   - `[[wikilink]]` **只指现存页**;未建页面写纯文字 + 「后续内容,未创建页面」。
   - **保留**「本质问答」类内容(如「为什么群有维数」「不变性是解集稳定而非解为常数」)——那些是真概念。

5. **重排索引**。整理后页数会变,`_索引.md` 按**主题分组**重列(本会话分五组:时空与对称性 /
   变分法 / 变分法的应用 / 轨道与几何方法 / 原始资料),入口页排在该主题组首位。

6. **质检 + 提交**(脚本见下)。

## 质检脚本(可直接复制,本会话验证可用)

```powershell
$files = Get-ChildItem "/mnt/e/notes/物理/理论力学" -Filter *.md
$all = Get-ChildItem "/mnt/e/notes" -Recurse -Filter *.md | Where-Object { $_.FullName -notmatch '\\\.obsidian\\' }
$base = @{}; foreach ($x in $all) { $base[$x.BaseName] = 1 }
"=== 断链 ==="
foreach ($f in $files) {
  $t = [IO.File]::ReadAllText($f.FullName)
  foreach ($m in [regex]::Matches($t,'\[\[([^\]]+)\]\]')) {
    $l = $m.Groups[1].Value -replace '\|.*$','' -replace '#.*$',''
    if (-not $base.ContainsKey($l)) { "BROKEN: $($f.Name) -> $l" }
  }
}
"=== 质检 ==="
foreach ($f in $files) {
  $t = [IO.File]::ReadAllText($f.FullName)
  $emo = ($t.ToCharArray() | Where-Object { [int]$_ -ge 0x1F300 -and [int]$_ -le 0x1FAFF }).Count
  $bad = [regex]::Matches($t, '\\\\[a-zA-Z]').Count
  $odd = (Get-Content $f.FullName -Encoding UTF8 | Where-Object { ([regex]::Matches($_, '(?<!\\)\$').Count) % 2 -ne 0 }).Count
  $src = if ($t -match 'sources: \[\]') { "空sources" } else { "" }
  if ($emo -gt 0 -or $bad -gt 0 -or $odd -gt 0 -or $src -ne "") { "问题: $($f.Name) emoji=$emo bad=$bad odd=$odd $src" }
  "{0,-40} {1,6}" -f $f.Name, $f.Length
}
```

**关键**:`$bad` 那条正则,**PowerShell 源码里必须写四个反斜杠** `'\\\\[a-zA-Z]'`
(两个反斜杠才是「匹配一个反斜杠」的 regex;写两个会全部误报,本会话曾误报 798 次)。

## 断链检查的例外(别改)

全库扫描会稳定报出这几类**非本次改动**的"断链",**不要动**:

- `log.md` 里指向已失效实体的链接——那是**变更日志的历史记述**;
- `README.md` 里 `[[数学/分析/_索引]]` 这种**带路径**的写法——basename 匹配器不认,
  但 Obsidian 能解析(或本就是纯文字导航);
- `代数III笔记.md` 里 `[[附件/xxx.svg]]`——**附件**,不是页面。

**做法**:先跑一次全库扫描摸清"底噪",再只看**自己改动涉及的文件**的断链;底噪不动。

## 常见误区

1. **只抽检不读全** → 漏掉重复段落这类缺陷(重复段必须逐页读完才能发现)。
2. **把"本质问答"当冗余删掉** → 那些是用户珍视的概念内容,只删**重复段**和**哲学漫谈**。
3. **顺手改任务范围外的页** → 用户只点名某课程时不要外溢到别的课程(可最后**询问**是否要一并做)。
4. **正文小节与顶层小节混用** → 「相关概念」「学习提示」在历史页里可能是 `###` 也可能是 `##`,
   统一到顶层 `##`。
5. **改完忘同步索引** → 页数/入口页变化后 `_索引.md` 必须重排,否则导航失效。
