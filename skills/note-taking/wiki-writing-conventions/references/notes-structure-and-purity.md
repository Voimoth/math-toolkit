# 概念页/笔记的拆分、vault 自包含、建页阈值

> 摘自 `wiki-writing-conventions` SKILL.md（2026-10-03 拆分），内容未改。

来源:`/mnt/e/pika文件_Pro/笔记共享vault.zip`(他人 vault;**源 zip 已于 2026-10 随 pika 目录清理**)

值得借鉴的 6 个方法(原记录在 `/mnt/e/notes/共享/SCHEMA.md`,**该文件已于 2026-09-11 删除,以下即权威版本,不再需要去 vault 里查**):

1. **问题驱动开篇**:每页从一个具体问题切入(如"问题0: ..."),再展开——而非纯定义先行
2. **Obsidian callout 分层**:`> [!question]` 问题 / `> [!note]` 命题 / `> [!tip]` 想法——视觉层次清晰
3. **编号递进**:`### 1.` → `#### 1.1`,想法可标 `想法1.1.1`,思路可追溯
4. **"想法"标注**:保留"为什么想到这么做"的思考过程,不隐藏动机(与因果链教学法一致)
5. **锚点交叉引用**:`[[page#小节]]` 精准引用,比整页链接更细
6. **开放结构**:未完成部分留空标题,笔记是"生长中"的,不追求一次写完

**结构化概念页的 callout 用法(2026-09 实践定型)**:用户要求"像傅里叶概念页那样用 tip/note 文本框分隔,使结构更清晰"。示范见 `/mnt/e/notes/数学/代数/代数III/概念/` 下的群论概念页(group.md、subgroup.md、normal-subgroup.md、quotient-group.md、isomorphism-theorems.md、derived-subgroup.md、group-action.md,入口为 group-theory-learning-path.md;原"群论讲义.md"大文件已按拆分原则拆成这些页):
- `> [!note] 定义/定理` — 陈述 + 公式(核心内容)
- `> [!example] 例子` — 具体实例、反例
- `> [!tip] 想法` — "为什么"、直觉、证明思路(因果链精神)
- `> [!warning] 陷阱` — 易错点(如"正规性不传递")
- 章节按主题分 `## 1. / ## 2.`,小节 `### 1.1`
- 末尾加"本章主线"因果链图(`群结构 → 子群/态射 → 陪集/Lagrange → 正规子群 → 商群 → 同构定理 → 群作用`),呼应因果链教学法

**概念拆分原则(2026-09 用户明确)**:不要把整门课堆进一个大文件——**每个概念一个小文件**(group、subgroup、normal-subgroup…),文件间用 `[[wikilink]]` 互链,Obsidian 关系图(Graph View)自动展示概念网络;另建一个 `<主题>-learning-path.md` 学习路径页作入口,用因果链串起全部概念页(示范:`group-theory-learning-path.md`)。互链写完后跑断链验证(脚本 basename 匹配;`log.md` 的历史记录链接与待建占位链接属正常)再提交。

**拆分要在动笔前就做,不要先写大文件再拆(2026-09-14 被斥)**:物理理论力学变分法答疑我先交了一个 12 节 / 14.5 KB 的单页,用户驳回:\"**那一个文件那么大, 你不会给不同概念用不同文件吗**\"。收敛做法是 **11 个概念页(每个 1.5–3.5 KB)+ 1 个入口页 `<主题>学习路径.md`**(因果链 + 概念清单 + 三句话),`_索引.md` 指向入口页。**判据:概念页超过约 4 KB、或含 3 个以上独立概念,即为该拆的信号。** 拆完后原大文件删除,并同步修索引与互链(勿留断链)。

**笔记文件(转写/讲义笔记)的拆分规范(2026-10-03 用户明确,与概念页拆法不同)**:
- **信号**:单篇笔记超约 **500 行(或 40 KB)** 就该拆;判据是"读者要在大文件里翻找"。已按此拆过:代数III 2314 行→9 篇、Fourier 1132→9 篇、习题课 752→6 篇、点集拓扑 565→4 篇、分析II 2874→12 篇。
- **按讲义章节拆,禁止按"上/下"对半切** —— 用户原话:「笔记不要分成两部分…不要像这样粗暴地分成上下」。拆到章级(或讲义的自然大节),每篇一个文件。
- **原文件名保留为入口页**(正文改为一句话 + 各章 `[[wikilink]]` 清单),**不要删掉原文件** —— 库里已有的 `[[Fourier笔记]]`、`[[代数III笔记]]` 等 11 处引用与概念页 frontmatter 的 `sources:` 自动继续有效,零断链。
- 文件名:**`NN-<章名>.md`(连续两位编号 + 连字符 + 章名)** —— **不带课程前缀**(用户 2026-10-03 定):课程/学科从所在目录就能看出,如 `Fourier/笔记/01-引言.md`、`代数III/笔记/正课/03-Sylow定理与A5单性.md`。
- **入口页统一叫 `00-总览.md`**(用户 2026-10-03 定稿):放在课程笔记根目录,列出各章 `[[NN-…]]`;引用它时**必须带路径**(同名 5 份,如 `[[分析III/Fourier/笔记/00-总览|Fourier 笔记]]`)。旧的 `<课程>笔记.md` 入口名已废。
- **同门课有正课 + 习题课两套笔记 → 各建一个子目录**(用户原话「不要区别对待」):`笔记/正课/`、`笔记/习题课/`,两套各自 `00-总览.md`;不要一套放根目录、另一套放子目录。仅一套的课程(仅正课)直接放 `笔记/` 根。
- **讲义提取文本**:同名多份时只留最新一份(判断依据:mtime + 行数 + 被概念页 `sources` 引用的是哪份),其余删——它们是 agent 工作副产物,用户授权自行处置、不必问。
- **每篇要有自己的 H1**:拆出的章标题升为 `#`,其下小节整体升一级(`###`→`##`);拆完逐篇检查"是否有 H1",不留无主标题的孤儿文件。
- **致命坑 —— 章标题与子节标题同级时不能按层级切**:某些笔记(实测 `习题课笔记.md`)章与子节都是 `## `,按 `^## ` 切会把每个子节当成新章,内容错位(拆出的两篇各只剩 15 行,原文件被入口页覆盖 —— 靠 `git checkout` 才救回)。**正确做法:用「标题白名单」切** —— 只在你指定的章标题集合处切开,其余行归入当前章。
- 连带修改:每篇 frontmatter(`title`/`updated`)、入口页、引用它的 `sources:` 字段、学科/课程 `_索引.md` 的描述文字;最后跑断链检查。



用户原话:「笔记和wiki里面不要保留指向本体的链接。我希望 git 上面的项目是一个独立的东西, 不依赖于我的其他本地文件。」本仓库是独立的文档库,换机器、单看 GitHub 也要读得通。规则:

- **正文里不写任何本地路径**:`/mnt/e/...`、`~/...`、`书籍/...` 一律删——需要指代时用文字(「讲义」「旧版」),不写路径。进 `log.md` 的历史记述同样去路径(只留文件名或纯描述)。
- **`sources:` 写讲义名称,不写文件名/路径**:用 `殷浩《分析 2》上册`、`Rosso《群论》讲义`、`Arnold《经典力学的数学方法》` 这种人类可读的名字;不写 `分析II(1).pdf`、`sofar_extracted.txt`。已全库改写 113 处(2026-10-03)。同理正文也不写「**讲义**:`xxx.pdf`」而写「**讲义**:殷浩《分析 2》上册(78 页)」。
- **OCR/提取产物(txt)不进 vault**:agent 读取/转写 PDF 产生的 `*.txt` 誊本、临时脚本、中间产物一律放**自己的目录**(`~/.hermes/cache/`),vault 里不留。历史遗留的 6 份提取文本已移出(2026-10-03),`.gitignore` 已加 `*.txt`。用户原话:「你以后读取文件也不要在我这里留下这种东西, 需要的话你把它放到自己的文件夹里」。
- **模板、脚本、工具一律不进 vault(2026-10-03 补充)**:用户原话「笔记模板也没什么保留的必要, 因为现在笔记都是你在写, 除非你觉得这个对你有用」——agent 直接 write_file 写页,不需要 vault 里的笔记模板;`共享/templates/` 已删。同理 agent 的读取/提取脚本不进 vault(用完即删;旧的 node/pdfjs 工具目录 2026-10-06 已清理,提取改用系统 pdftotext/tesseract)。**唯一保留的非 md 文件是 `共享/git-hooks/pre-commit`**——它是仓库自己的护栏(拦住 >5MB 文件进历史,防止 .git 再攒出百 MB 孤儿对象),不是 agent 的工作脚本,换机器照抄即可。
- **删完文件要顺带改掉技能里的指令**(见 §3「删除被跟踪文件后:必须清理指向它的指令」):本次删 README/模板/scripts 后,skill 库里 7 个文件的路径与「README 登记」类句子都要同步改,否则下次会话照着一本不存在的文件找。
- **判据**:这个文件单独 clone 到一台没装任何本地资料的新机器上,还有没有读不通的地方?有 ⇒ 还没干净。
- **不嵌用户手绘/扫描图的裁片(2026-10-03)**:需要图示时**优先文字描述**(几何过程逐步讲清),文字不济再**自绘简洁 SVG**;不要把原 PDF 某页的图裁出来放进 `附件/`。用户原话:「不要放我手绘的图片,要么自己画 svg 要么不用图片,尽量用文字表述」。

**概念页 ≠ 题解汇编(2026-09-14 用户斥责,最重要的一条边界)**:沉淀作业答疑时极易把概念页写成\"作业第 X 题\"的题解合集——题号、**题目专属数值与算例**、\"与题给 (X) 式一致\"这类做题痕迹、\"交作业时建议加一句说明\"、某个具体题目的凑题推导。用户原话:\"**概念里面有必要放这么多题目吗, 你知道'概念'两个字什么意思吗**\"。规则:

- **删掉**:题号、题目专属数值与算例、凑题过程、作业建议、与题面对照的措辞。
- **保留**:概念本身(定义、为什么成立、证明要点、方法对比)与**概念性**陷阱(如\"全导数积分为零\"要分三步、折射率里的因子 2、对称化是纯记账)。
- **判据(一句话)**:这句话**换个题目还成立吗**?不成立 ⇒ 属于题解,不进概念页。题解留在课程级 coaching 技能的 `references/` 里。
- **笔记也不要单独的「作业/练习」章(用户明确要求)**:整理习题课/讲义笔记时,不要把作业题收成一章(如「§7 作业与练习」)。只把**与讲义正文强相关**的题作为 `> [!example]` 例题或 `> [!exercise]` 练习**内嵌进对应小节**——例题服务于它所在那一节(说明概念怎么用);**不写作业编号或出处**(「出现在第 X 次作业中」这类话一律不要);与正文无直接对应的题**直接舍弃**。判据同上:这题换个语境还成立吗?
- 概念页的\"陷阱\"框要写**通用陷阱**,不写\"这道题容易算错的地方\"。

**笔记/概念页统一结构(2026-09-02 用户要求"以后的笔记都维持统一的风格")**:
- **内容逻辑优先于小节机械对齐(2026-09-02 用户修正,最高优先)**:例子框进 callout 后,应紧跟它所阐述的概念(如"Exemples de groupes"贴着 Groupe 定义),即使这会插在两个并列定义小节之间——用户原话:"笔记结构化之后例子放在中间就不影响阅读了。整理笔记的时候还应该更注重内容的逻辑"。**不要为了小节对称把例子流放到概念后面**
- **严禁向 OCR 转写/用户笔记添加原文没有的内容(2026-09-02 用户怒斥教训)**:曾编造"H 與乘法構成群(见定义式简略,OCR 原文仅列名目)"插入笔记(原文只是光秃秃的列表项),被用户发现。规则:`笔记\` 转写文件里**每个字必须能在原始转写中找到对应**——不补定义、不写"见 xx"导航句、不加结构说明 meta;原文缺的就是缺的,宁可留白。格式可以改(callout/小节),内容一字不增
- **数学/物理答疑的归档**:数学和物理回答完成后，直接更新对应课程的`概念/`页；内容应与用户原始课程笔记分离，不能写入`笔记/`。概念页优先按问题驱动和因果链组织，保留严格条件、证明要点、例子和陷阱。
- **数学辅导内容的法语对照**:讲解数学课程时，概念首次出现应同时给出中文名称、法语名称和标准记号，便于用户与课程笔记逐项对照。物理概念首次出现可附英文术语。例如“正规子群（sous-groupe distingué，记作 \(H\trianglelefteq G\)）”。

**讲义/OCR 校对的确定性分级**:发现明显的 OCR 记号错误（如花体 \(\mathfrak S_n\) 被识为 `G_n`）可以直接修正；仅凭上下文怀疑、但可能改变数学含义的截断句、缺失括号或公式，必须先列出位置并询问用户。修正后要重新搜索整个文件确认旧错误无残留，不能只检查局部读取结果。

**定义主干对齐**:Groupe/Sous-groupe/Morphisme 这类并列定义各占一个 `### x.y` 小节;例子的"不打断"由 callout 框解决,而不是靠挪走例子
- **例子框进 `> [!example]`、注记/备注框进 `> [!info]`、警告框进 `> [!warning]`、直觉/原理框进 `> [!tip]`**——视觉上"定义是主干,例子是旁注"
- 规范同时适用于 `概念\` 知识库页与 `笔记\` OCR 转写页(示范:代数III笔记.md 重构后 13 个 callout;Fourier笔记.md 10 处 `>` 引用块批量转 callout)
- 批量转换技巧:按行号定位引用块、**自底向上替换**避免行号漂移;标题从内容前缀剥离(正则兼容全角/半角标点),剥离失败就保留全文(无害);转换后验证"奇数 $ 行 = 0、坏转义 = 0、callout 计数符合预期"

**法国数学排版/记号约定(用户任课老师的写法,写公式与笔记时遵守)**:
- **转置上标 t 写在矩阵左上角**:LaTeX 用 `{}^{t}P` 或 `{}^tP`,**不用右上角的 `P^t`**。
- **术语记号跟随老师讲义**:如 `Z(a)` 记**中心化子**、`Z(G)` 记**中心**,且 `Z(G) = ∩_{a∈G} Z(a)`。写概念页/讲解时与课程笔记保持同一记号,别自行换成其他教材的写法。
- 概念首次出现附法语名称(见上文「数学辅导内容的法语对照」);物理概念首次出现可附英文术语。

**建页阈值(Page Thresholds)**:
- **创建页面**:概念/实体在 2+ 来源出现,或是一个来源的核心主题
- **追加已有页面**:来源提到已有覆盖的内容时
- **不创建页面**:一笔带过的提及、微小细节、域外内容
- **拆分页面**:超过约 200 行时拆分子主题并互链(与上文「概念拆分原则」一致)
- **归档页面**:内容被完全取代时移入 `_archive/`,并从 `_索引.md` 移除

**更新政策(Update Policy)**——新信息与已有内容冲突时:
1. 检查日期,较新来源通常取代较旧的
2. 若确实矛盾,注明两种立场及各自日期与来源
3. 在 lint 报告中标记,供用户复核
(注:不再使用 `contradictions:` frontmatter 字段,该字段从未在 vault 中实际使用过)
