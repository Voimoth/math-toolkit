# 更新授权与「新想法」沉淀

> 摘自 `wiki-writing-conventions` SKILL.md（2026-10-03 拆分），内容未改。

- **数学/物理问答直接更新 wiki,无需询问**:用户原话"我问的数学和物理问题都可以不加询问地更新进wiki"。讲解/答疑后自动沉淀到对应概念页(概念页 + 互链 + index + log + git push)
- **禁止询问是否沉淀(硬性,2026-09-05 用户怒斥"我说了多少次整理 wiki 前不需要问我")**:概念性问答讲完后**当轮直接写入**概念页,禁止用"要不要整理进 wiki""我可以之后补进 wiki 吗"等句式询问——用户视为冒犯。讨论未完无法立即写时,在本轮对话结束前补上,不拖到"之后"。
- **边教边沉淀,不要攒到最后(2026-09-14 用户明确)**:多步教学/陪练会话中,用户原话"**一边做一边整理, 不要攒到最后**"。
  - 判据:**某个子主题已经讲完、自成一体**时就落地成页,不等整场会话结束;剩余未讲的题目只留指针。
  - 典型形态:长作业/多小问被拆成多次对话。**每个已经讲透的概念页当轮就建好并 push**,而不是等 8 个题全讲完再一次整理。
  - 好处:会话中途被打断/上下文被压缩也不丢已产出的内容;用户能看到进展。
  - 注意:只沉淀**已讲完**的部分;尚未讲的题在页内用"后续内容,未创建页面"的**纯文字**带过(不加 `[[wikilink]]`,见 §4b),不要提前建空页。
- **"参考格式不抄内容"原则**:借鉴他人 vault 时只学组织方法(问题驱动/callout/编号),不复制其笔记内容——用户原话"参考别人的格式和方法,而不是参考他的内容"
- 理论力学新课程已开(Arnold《经典力学的数学方法》),概念页按同套格式维护
- **用户会直接改 vault 里的文件——接手前先 `git diff`(2026-10-03)**:仓库挂在他自己机器上,他会随手编辑笔记(本次他改了 `分析I/笔记/10-…` 的三行公式,只在对话里说一句「我按你的提示改掉了一些问题」)。所以动笔前先 `git status --short`;**有改动就 `git -c core.quotepath=false diff -- <文件>` 看清他改了什么**,再决定要不要接着改、以及要不要在 log 里记一笔。
- **用户给出的修正也要独立验证(2026-10-03)**:他说「你确认一下应该没问题」时,要逐一核**数学成立性**,不能照抄放行。本次他改的三处:两处成立($2^n\le C_n^{2n}\le 2^{2n}$ 两侧都对;改成指数形式后虽更弱但与下一行及最终结论自洽),第三处仍留缺口(中间用到 $C_n^{2n}\ge\frac{2^{2n}}{2n+1}$ 这个下界却没写出来)。**规则:他的判断(原稿到底写了什么)优先于你的猜测,但"改得对不对"必须你自己算一遍**,有缺口就直说。
- **他回复存疑点的三种处理**:①给出明确答案(「不是 iff, 是 or」)→ 直接改并说明依据;②「改掉或者标记一下」→ 二选一,选了要讲清(本次保留原稿 + 加括注给出正确形式);③**未置评的条目 → 保留原文 + 保留 `[?]`**,不要自己拍板,也不要因为"看着像笔误"就静默改数。



用户原话:「那些学习过程中的新想法新思路应该由你及时整理到概念文件中，比如昨天的那些讨论，我认为这些比单纯的概念更有价值。」

- **不只标准概念要沉淀**:答疑/陪练中产生的**原创思路、非标准证明、用户自己走通的证明骨架**也要**当轮**写进概念页——用户明确说这类内容价值高于单纯的概念罗列。
- **形态**:作为对应概念页的 `> [!tip] 想法` 或 `> [!note] 命题 + 证明` 小节;内容够独立就单独成页(如「X 的另一种证明」)。
- **仍守概念页铁律**(§2):写方法/思路/为什么、关键步骤、它比标准证法强在哪;**不写**题号、题目专属数值、解题过程流水账。
- **实例(2026-10-02 讨论,已沉淀)**:① $A_4$ 没有 6 阶子群的「$g^2$ 必须落在 $H$ 或 $g_0H$」排他式证明(不用正规性,用户独立发现);② 指数 2 ⇒ 正规 的两种证法(陪集版 + 作用/同态版)。落在 `数学/代数/代数III/概念/` 对应页。
- 与 §4「边教边沉淀」同源:**判据是「这个思路已经成形」**,而不是「整场会话结束」。
- **记录来源必须分清(用户纠正)**:写进技能或概念页的「要求/教训」要标明是**用户明确要求**还是**agent 自己的复盘结论**;**绝不可把自己的自我批评写成用户的要求或抱怨**——用户会当场否认(「我从来没抱怨过这件事,这句话从头到尾都是你自己脑补的」)。发现记错就当轮修正那条失实记录,别叠"UPDATE:实际上…"。
