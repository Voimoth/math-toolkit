## 分离变量法因果链(四连问)

1. **为什么非零常数边界不能直接分离?** 代入 $X(0)T(t)=a$ 强迫 $T$ 为常数,只剩稳态。处理:减稳态解 $v=a+(b-a)x/l$($v_t=0=v_{xx}$,真特解,一次吸收非齐次性),$w=u-v$ 是纯齐次问题。
2. **为什么时间依赖边界 $\alpha(t),\beta(t)$ 不能照搬?** 逐时刻插值 $v=\alpha(t)+(\beta(t)-\alpha(t))x/l$ **不满足热方程**($v_t\neq 0$),只是边界插值函数(lifting)非特解;平移后方程带源项 $f=-v_t$。非齐次性是守恒量:只能从边界转移到方程,不能消灭。
3. **怎么解带源项问题?** 特征函数展开 $w=\sum w_n(t)\sin\frac{n\pi x}{l}$ → 系数 ODE $w_n'+\lambda_n w_n=f_n(t)$ → 积分因子 → Duhamel:$w_n(t)=e^{-\lambda_n t}g_n+\int_0^t e^{-\lambda_n(t-s)}f_n(s)ds$。本质 = 无穷维常数变易法。常数边界是"源项响应为零"的特例,退化为"特解+齐次通解"。
4. **为什么不会漏解/展开凭什么合法?** 不漏解=完备性+验证+唯一性(能量方法)。展开:写出级数(系数=积分)永远合法;级数=函数需要 Dirichlet 定理(逐点,已学)+ $L^2$ 完备性(课程欠账);$t>0$ 时 $e^{-\lambda_n t}$ 指数衰减使验证步远易于 $t=0$。
5. **通用三项结构**:$u=\text{lifting}(\text{吃边界})+\text{初值响应}+\text{源项响应}$。$e^{-\lambda t}$ 型边界可令 $u=e^{-\lambda t}X(x)$ 一次吸收,无需 Duhamel。

## Fourier 展开自检法(用户提交展开式时先查这三件)

1. **常数项 = 周期平均**:$\frac{1}{T}\int_{\text{周期}}f$。例:$|\sin t|$ 周期 $\pi$,平均 $2/\pi$(常被误写 $1/\pi$,$\int_0^\pi\sin t\,dt=2$ 非 1)。
2. **特殊点代入**:$t=0$ 时 $|\sin 0|=0$,用 $\sum_{n\ge1}\frac{1}{4n^2-1}=\frac12$(裂项望远镜)验证。
3. **归一化因子按周期**:周期 $\pi$ 基 $\{\cos(2kt)\}$,$\|1\|^2=\pi$,$\|\cos(2kt)\|^2=\pi/2$($k\ge1$);直接套周期 $2\pi$ 公式系数全错。正确展开:$|\sin t|=\frac{2}{\pi}-\sum_{n\ge1}\frac{4\cos(2nt)}{\pi(4n^2-1)}$(系数 $-4/(\pi(4n^2-1))$ 由 $\int_0^\pi\sin t\cos(2kt)dt=\frac{-2}{4k^2-1}$ 得来)。

## 经典题路线:$\lim_{n\to\infty}\int_0^1 f(x)|\sin nx|\,dx$(分析3 习题 1.3 类)

- 答案:$\frac{2}{\pi}\int_0^1 f$(常数 = $|\sin|$ 周期平均)。
- 路线 A(Fourier,贴课程):展开 $|\sin t|$(周期 $\pi$ 偶函数,只含 $\cos(2kt)$)→ 代入 → 主项 $a_0\int f$ + $\sum_k a_k\int_0^1 f(x)\cos(2knx)\,dx$。
  - 关卡 A(逐项积分):$a_k=O(1/k^2)$ 绝对可和 → Weierstrass M-检验 → 一致收敛。
  - 关卡 B(极限换序):$\int f\cos(2knx)dx\to0$(Riemann-Lebesgue,讲义 §3 Dirichlet 证明用过);余项 $\sum_{k>K}|a_k|\int_0^1|f|$ 与 $n$ 无关 → 换序合法。**需要 $\int_0^1|f|<\infty$**(绝对可积);若 f 仅条件可积需标注此处失效——对应题目"可积或绝对可积"措辞。
- 路线 B(周期分割):按 $\pi/n$ 周期段划分 + 可积函数逼近/控制收敛(6.19),不需 R-L 但逼近论证更长。
- 陪练提示顺序:先算 $c=\lim\int_0^1|\sin nx|dx$ 猜答案 → 让用户选路线 → 让用户自查"为什么只含 $\cos(2kt)$"、"归一化因子"、"两道关卡"。
