## 课程总地图(因果链主线)

```
群(公理) → 子群/生成子群 → 陪集/Lagrange → 同态/核 → 正规子群 → 商群
→ 同态基本定理(1/2/3) → 导群/交换化 → 简单群 → 群作用 → 轨道-稳定子
→ [后半:续篇] G-等变 ψ:G/Stab(x)→O(x) → Stab(g·x)=g·Stab(x)g⁻¹
→ 作用核=∩aHa⁻¹(非忠实) → 无限群+有限指数子群⇒非单
→ 共轭作用/中心化子(翻译表:轨道=共轭类,Stab=Z(a),不动点=Z(G),|Cl(a)|·|Z(a)|=|G|)
→ GL 分类(等价=秩/相似=共轭/同余=^t) → 类方程 → k-群: |X|≡|X^G| (mod k)
→ p-群中心非平凡 → Burnside: N=(1/|G|)Σ|Fix(g)| → 传递⇒无不动点元
→ SO(3) 有限子群分类: C_n / D_{2n} / A4 / S4 / A5 (N=2 或 N=3 的轨道计数)
→ Sylow 引入: Lagrange 逆命题反例 A4(无 6 阶子群) → p-群有 p^i 阶子群(归纳+中心)
→ Sylow 定理(存在/共轭/计数) → 对称群: S_n 生成元·循环分解·共轭类(循环型) → A_n 单性
```

## 已沉淀的教法与混淆点(2026-09 实战)

1. **同构 ≠ 作用**(用户真实卡点:"D_{2n} 的旋转不区分奇偶顶点,为什么 G≅D_{2n}?"):
   - G≅D_{2n} 是代数事实:生成元 ρ(主轴 2π/n)、r(180° 翻转)满足 rρr⁻¹=ρ⁻¹。
   - "旋转区分奇偶"是 G 作用在赤道 2n 个点上(正 2n 边形,每次走 2 格)的特征;2n 阶群在 2n 点上不可能传递(稳定子≥2)。
   - 用户直觉里"不区分奇偶的群"是正 2n 边形的等距群 D_{4n}(4n 阶)。D_{2n} 按讲义定义=正 n 边形等距群(2n 阶)。
   - 总结语:**同构不携带作用信息;轨道结构属于作用,不属于群**。
2. **几何/轨道内容先给具体坐标装置,再抽象**:用户对"A4 的轨道是哪三种"的抽象轨道表(顶点/面心/棱中点方向)没懂;换成单位球内接正四面体坐标(v1=(1,1,1)/√3 等)后逐根轴、逐个极点"点名"(3 阶轴 4 根贡献 ±v_i,2 阶轴 3 根贡献 ±e_j),用户立刻懂。教训:轨道表之前先让对象"落地"。
3. **记号尊重老师**:讲义用 Z(a) 记中心化子(与中心 Z(G) 同字母)。用户明确"既然学这个老师的课就忠于他的记号,何况 Z(G)=∩Z(a) 体现概念联系"。不强制改 C_G(a),讲解时提示易混即可。

6. **把环论/模论的对象搬进群论(2026-10-03 复习首轮暴露)**:他问「伽罗瓦群不是多项式环的理想吗?
   (群) 要几层跟模掉的那个理想的生成元个数有关吧?」——这是他自述「学过但没掌握」的典型表现。
   **对策:先把对象分层摆清,再讲链子**:
   $f\in K[X]$ → 理想 $(f)\subset K[X]$ → 商环 $K[X]/(f)$(不可约时是域 $\cong K(\alpha)$,即「加一个根」)
   → **伽罗瓦群 = $f$ 的根上保持全部多项式关系的置换群**(是群,不住在 $K[X]$ 里)。
   关系一句话:理想 $(f)$ 划定「根集 + 根间全部关系」这个**对象**,伽罗瓦群是这个对象的**对称群**
   (接他概念页 `自同构与群的对称性`)。
   **「生成元」两边都能说**,别让他以为只属于理想:$f$ 生成 $(f)$、$(12)(123)$ 生成 $S_3$
   (= 他笔记 01 的生成子群 $\langle S\rangle$)。

11. **「线性空间自带一个群」vs「研究群到线性空间的作用」（2026-10-04，他的原话是「感觉有点奇怪」）** ——
   又一类**对象/主语混淆**：他发现「群论 1900 年前后就在研究 $G\to GL(V)$，可 $GL(V)$ 本来就是线性空间自带的群」。
   答法（照此顺序）：① 先承认「自带」对 —— $GL(V)$ 是**线性结构的自同构群**，与集合自带 $\mathfrak S(X)$、
   欧氏空间自带 $O(V)$、方程根集自带伽罗瓦群是同一个通例（接他概念页 `自同构与群的对称性`）；
   同时**顺手校一个时间点**：1900 年群论早已是学科（Jordan 1870、Burnside 1897），表示论是**学科建立之后**的事，不是「刚起步时」。
   ② 再点出**表示论的主语不是 $GL(V)$**：问的是「$G$ 能不能、以多少种方式坐进 $GL(V)$」。
   ③ 摆三个对象让他自己对号：$G$（被研究者）/ $GL(V)$（舞台；本身也可被研究 —— $GL_n,SL_n,PSL_n$ 在他课程后半）/
   **表示 $\rho:G\to GL(V)$（真正的新对象：同一个 $G$ 有无穷多表示 ⇒「表示的分解与分类」成新问题）**。
   ④ 目的：把群的问题搬进唯一「什么都算得出」的结构（迹、特征值、维数、Jordan 型）。
   **一般化**：他问「这（不）自洽 / 有点奇怪」时，多半是把两个对象合成一个、或把主语搞错 —— **先拆对象与主语，再讲道理**。
   落盘：`概念/群作用.md` 的 callout「线性表示与『线性空间自带的群』是什么关系」。
12. **「当年是用什么语言写的？」——第三类混淆：语言/表述层（2026-10-04，接在史线末尾）**
   他连问两次：①「向量空间还没有明确定义的时候是怎么有线性代数的」；②「Jordan 标准型很依赖线性映射，
   当时的证明是用纯矩阵语言写的吗」。
   **答法（两句成套，缺一不可）**：
   - **先摆语言谱**：同一份数学内容在不同年代是用不同语言写的 —— 方程组/行列式（Leibniz 1693、Cramer 1750，中国《九章算术》早有消元）
     → 坐标（Descartes 1636）→ 型/二次型（Gauss 1801、Weierstrass 1868）→ **线性替换 substitution**（Jordan 1870，书名就是 *substitutions*）
     → 矩阵（Cayley 1856/1858）→ **模**（20 世纪：$V$ 是 $K[X]$-模 + PID 结构定理）；
     抽象向量空间的定义迟至 **Peano 1888**，抽象化普及到 1920s。
   - **再点破错觉**：他（和多数人）会以为「这个概念依赖线性映射」/「没有定义就做不了」——
     其实**依赖的是线性结构**（加法 + 数乘 + 换基），「线性映射 / 向量空间」只是后来给它找的语言容器。
     史书原话（en-wiki《Linear algebra》，可直接引）：「…without even defining an abstract vector space: nor is there anything
     to suggest they suffered thereby.」
   **一般化**：他问「当时是不是用 X 语言 / 为什么那时没有 Y 还能做 Z」时，**先分「对象 / 主语 / 表述语言」三层**，
   再指认他混的是哪一层 —— 这与他第 6、11 条的毛病同源（对象不分层），只是这次混的是**语言**而非对象。
   落盘：`概念/群论的目的与历史.md` 的「概念出场顺序」节（含标准型的语言史与史书原话）。
13. **他会要「穷尽性」**：凡报分类清单（「8 阶有这 5 个」「12 阶有这 5 个」），必须同时给**为什么只有这几个**的骨架 ——
   穷尽性的入口通常是 Sylow + 元素阶论证（8 阶：非阿贝尔 ⇒ 无 8 阶元、不能全 ≤2 阶 ⇒ 必有 4 阶元 ⇒ 指数 2 的 $C_4$ 正规 ⇒ 解正合列）。
   只给清单他会停下追问；且报清单时要指明「算出来落回阿贝尔旧清单 ⇒ 本支被排除」这一步。
14. **抽象拼装的产物「认不出是哪个熟悉的群」**（他问「怎么认出这是 $A_4$」）⇒ 固定三步：
   ① 列全 $X$ 的定义性事实（有正规 $K$、$X/K\cong\cdot$、作用是否非平凡）；② 在候选群里用具体元素逐条点出（如 $x(12)(34)x^{-1}=(14)(23)$）；
   ③ 用本支「只有一个同构类」收口。再加一条区分指纹（2 阶元个数：$A_4$ 3 个 / $D_{12}$ 7 个 / $Dic_3$ 1 个）。**只说「它就是 A₄」不算回答。**
15. **他半直积乘法算不稳时，换加法记号重写**（$N=\mathbb Z/n\mathbb Z$，$(n_1,q_1)(n_2,q_2)=(n_1+f_{q_1}(n_2),q_1+q_2)$）——

21. **$S_\infty$ 与「Schur 把有限群推广到无穷」的误读（对象层，与第 1、11、12 条同源）**：
   他问「讲座里的 $S_\infty$ 就是 Schur 把有限置换群推广到无穷吗」——不是。$S_\infty=\bigcup_n\mathfrak{S}_n$ 只是定义 $\Lambda(x)$ 的**量化装置**（递增并，作用在变量集 $\{x_1,x_2,\dots\}$ 上），讲座不研究它的表示、共轭类、特征标（它不是有限群，没有正交关系那套工具）。
   Schur 推广的是**函数**：$s_\lambda$ 对任意分拆有定义，$\ell(\lambda)\le n$ 时 $n$ 变量 Schur 多项式与无穷变量版逐项一致（稳定性）；且史序相反——Frobenius/Schur 做的都是**固定 $n$** 的 $\mathfrak{S}_n$ 与 $\mathrm{GL}_n$，$\bigcup_n\mathfrak{S}_n$ 的写法属现代对称函数教材框架（此条未逐条核实，讲时标「推断」）。

   **不许自造隐喻动词** —— 曾把这两个动作叫「搬」「转」，他当场判为「明显是机翻表达」（send 的直译）；标准说法是「映成」「沿循环走 $k$ 步」「交换两条循环」。
   ② 每件事的奇偶用**换位个数**算（映成另一条同长循环 $=d$ 个换位，$d$ 偶时是奇置换；沿循环走 $k$ 步 $=k(d-1)$ 个换位，只有 $d$ 偶且 $k$ 奇才奇）；
   ③ 一个具体例子垫底（$A_3$ 的 $(123)$ 特殊、$A_5$ 的 $(123)$ 非特殊，那里的奇 $\tau$ 就是 $(45)$）；

   通则：一段讲解里若连续出现三个以上下标记号，就换成一个具体循环上的动作描述 ＋ 一个最小的例子。

- **他说「直接写过程 / 直接给答案」就立刻给完整解答，形态是渲染好的图**：完整证明用 `ctexart`（10.5pt、margin 1.5cm、`enumitem nosep`）排 A4，`xelatex` 编译后 `pdftoppm -r 150 -png` 出每页 PNG，用多条 `MEDIA:` 一起发；正文消息只留两三行引路。

## agent 讲 Sylow / 正规化子类论证时必须自查的三处（agent 自己会犯）

1. **「$PQ$ 是子群」不能默认**：$|HK|=|H||K|/|H\cap K|$ 对**集合** $HK$ 总成立；
   $HK$ 要是子群需 $P\subseteq N_G(Q)$ 之类的额外条件。
2. **子集大小不整除群阶**：$PQ\subseteq N_G(A)$ 只给 $|N_G(A)|\ge|PQ|$；
   要写出 $d\mid|N_G(A)|$ 必须先有 $PQ\le N_G(A)$ 是子群。
3. **共轭作用的核是 $\bigcap N_G(P)$，不是 $\bigcap P$**：$G\curvearrowright\mathrm{Syl}_p(G)$ 的核只给 $|\ker|\mid|G|/n_p$。
   写错就**当场撤回**并明确「以这一版为准」——他会逐句核。
