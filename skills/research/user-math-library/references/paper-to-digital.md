# 纸质书转电子档：取扫描件的四条路（不是逐页拍照）

用户问「纸质书想转成电子档」时用。触发句：纸质书、实体书、扫描成 PDF、买不到电子版、要不要买扫描仪。

按省力程度排，**先做完第 0 步再谈设备**。

## 第 0 步：先查有没有现成电子版（省钱省时最多的一步）

中科大订阅 Springer / AMS / EMS，超星-读秀可文献传递；数学经典教材命中率很高。
十分钟的查证常常省掉全部扫书工作。查不到再往下走。

## 手机 + 支架 + vFlat Scan（免费，安卓）

- 免费版据应用商店页：不限量、无水印；支持**自动捕获**（页面稳定或翻页后自己拍，不用按快门）、
  **双页跨页自动拆成两张**、**曲面展平**（厚书不必压平）、**去手指**。
- 瓶颈从「按快门」变成「翻页」，量级是一小时一两百页。
- 拍摄条件比算法重要：手机**固定**角度、开台灯避开反光、书居中。别手持。
- 适合：孤本、讲义、旧书、舍不得拆的书。

## 寄书代扫（淘宝，最省人力）

- 拆书扫描 **300dpi ≈ 0.05 元/面**、**600dpi ≈ 0.1 元/面**；不拆书约 0.2 元/面。
- 600 页的书 ≈ 30–60 元，几天回 PDF；打印店现扫不拆书约 0.2 元/面（1000 页 ≈ 200+ 元，更贵且不一定清晰）。
- 代价：**书基本回不来**（拆书=切脊）。只适合确定要电子版、纸质可以牺牲的书。
- 下单前确认：拆不拆、dpi、是否做文本层/OCR、页序校对谁负责。

## 自己拆 + 馈纸式扫描仪

- 参考机型爱普生 ES-580W：京东约 2899 元（官网建议零售 3899），35 ppm / 70 ipm、ADF 100 页，
  600 页的书半小时扫完。
- 只值得在**要扫几十本**时买；扫一两本永远不如代扫合算。
- 事先确认书脊能拆（胶装可切，锁线/精装要么拆坏要么买不拆书方案）。

## 高拍仪（不拆书的折中）

成者 Czur 一类，800–2000 元，A3 幅面、曲面展平、脚踏翻页。
**本机没有实测过这类设备，价格与效果属于二手信息**——推荐时要标明这一点，别当成已核实的结论。

## 数学书的产物形态（决定后续所有工序）

- **不要追公式转 LaTeX。** 可靠产物是「**图像 PDF + 隐藏文本层**」：版面原样保留，文字可搜索/可复制/可进 RAG，
  公式看图。这已经够查定理、引用页码。
- 真要结构化某几页的公式，再单独把**那几页**交给视觉模型，成本低得多。
- 分辨率：灰度 300 dpi 对纯文字足够；彩色 600 dpi 体积大 5–10 倍，除非有彩色图示否则不必。
- 文本层在本机怎么做：`pdftoppm` 出图 + `tesseract`（chi_sim/eng/fra 已装），完整管线见 `scanned-pdf-ocr.md`。
- 扫描件没有文本层就检索不到（旧 math-rag 会记 `pages = -N` 跳过；该 RAG 已于 2026-10-20 拆除）。要做全文检索得先 OCR；只想知道「哪本书讲这个」用 `bookdex` 的目录索引即可，不必 OCR。

## 选择口径

- 经典教材 → 先查电子版，多半不用扫。
- 纸质孤本 / 讲义 / 旧书且量少 → vFlat，别买设备。
- 量大（几十本）且纸质可牺牲 → 代扫或自购馈纸扫描仪，算一下单价再决定。
