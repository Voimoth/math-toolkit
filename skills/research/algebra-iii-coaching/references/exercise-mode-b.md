# exercise-mode-b（自 SKILL.md 搬家，原文零删改）

## 题集带做（模式 B 变体）

- 他一句「带我做下载里的题」就是要**陪练式复习**，按 math-coach 模式 B：一次一题、**只给目标不铺路**、
  他卡住时给「最小关键引理」（不是完整证明）、**一轮一问**、做完才下一问。
- 他常**跳过收尾**（第 1 问最后一步没写就攻第 2 问）：提醒一次即可，别追。
- 证明类题他要「最短够用」；**他提出的更短写法直接采纳并说它更好**，不要维护自己那版。
- **题在习题课讲义里出现过时，先读讲义找它自己的路线**（他会直接说「按里面的思路讲」）。讲义给的是课程内的机器，通常比 agent 自造的短：如《2026-10-22 循环分解 1》用 Frobenius 不变因子把「互素两循环块 ≃ 循环」压成次数夹逼三行，而 agent 先写的 Bézout 造投影虽然也对、却多一层装置。读了讲义再落笔，并在回复里点明两种走法的差别（他看重这个）。
- 题目地图、已确认的论证骨架、三个自查陷阱、以及数学法语措辞 → `references/exercise-sets.md`。
- **转述题目前先用 `pdftotext -layout` 核原文**：`read_file` 的 PDF 提取会把数学符号整段吞掉（实测丢过 `ε(τ)`、`⊂`、`sσs⁻¹`），
  于是“偶数基数轨道”会被写成“奇数”——他会一句抓住。奇偶、量词、指数是最高危项。
- **分式会被整个吃掉**：`\prod_{k=0}^{n-1}\frac{p^n-p^k}{p-1}` 提取成 `k=0 (p 1)`，分母消失；照它讲题就是事实错误（原话「分母怎么被你吃了？这样题目就太宽松了」）。
  凡题目带分式、根号、求和上下限、分段括号：**先渲图再开口** —— `pdftoppm -r 200 -f <页> -l <页> -png <题纸> /tmp/p` 后用视觉模型读该页，
  确认分子分母与上下限再转述。这是公式类题目的第一步，不是「存疑才查」。
- **讲到“某元素/某循环的轨道”时，开口就交代是哪个群作用在哪个集合上**（如 $\langle\sigma\rangle$ 作用在 $\{1,\dots,n\}$），
  并注明这与 $\mathfrak S_n$ / $\mathfrak A_n$ 的共轭作用无关——他第一个追问必是这个（同上方第 8 条“先交代宾语”）。
- **他说「直接写过程 / 直接给答案」就立刻给完整解答，形态是渲染好的图**：完整证明用 `ctexart`（10.5pt、margin 1.5cm、`enumitem nosep`）排 A4，`xelatex` 编译后 `pdftoppm -r 150 -png` 出每页 PNG，用多条 `MEDIA:` 一起发；正文消息只留两三行引路。
  中文正文里的 `\Longrightarrow`、`\iff`、`\cup` 必须写在数学模式内：**裸 Unicode 箭头在 CTEX 正文字体里静默缺字**（日志里是 `Missing character`，渲染出来是空白），发图前 grep 一遍编译日志。
- **讲一道题的默认交付形态是「法国题式小结论链」，不是「定理–证明」块**：3–5 条编号小结论，每条只写断言 + 一句依据，
  最后一句说明它们怎么拼出命题；**细节被问到时才拆那一条**。他原话：「就想法国人出题目一样，用几个小结论拼出最后的结果就行。
  如果我问你某一步怎么来的，再把那一步拆开」。判据：每条能不能单独抽出来当一个引理？不能就是没拆到结论层。
- 他要「作业稿」或明说「直接写过程」时，才用完整排布：记号 → 引理 → 逐小问（$\Longleftarrow$ / $\Longrightarrow$ 分开）→ 每个 $\square$ 前一句点明用了哪个假设；
  例子挂在对应小问后面，不堆在开头。发图前 `grep -i "missing character"` 编诐日志。
- 表达层的全套规则（句子层、分段、动词中英对照、`scripts/prose_lint.py`）在 `math-coach` 的 A24 与 `references/mathematical-prose.md`；
  **math-coach 是 user-owned，复盘轮不能自动改** —— 那边需要修正时告知用户跑 `hermes curator adopt math-coach`，或把内容层改动落到本技能的 references 里。
- 他问「这句法语怎么写」时给**可直接抄的句子 + 用法差别**，别讲语法：
  不妨设 `quitte à + 不定式`（后接具体动作 remplacer/conjuguer/renommer）；较笼统用 `sans perte de généralité`；
  归约到用 `on se ramène au cas où`（他笔记 08 讲义就是这个用法）。
