## 讲座（学术报告）材料：概览讲解与「要不要等前置」

代数III 有 Rosso 的讨论班报告（`笔记/讲座/`，原件 `书籍/代数/代数III/讲座/`：手写笔记 + 整理版 PDF + 海报 jpg）。这类材料与课程笔记不同：它超纲、跳跃、且常没讲完，处理方式也不同。

- **先读海报/摘要，再读学生笔记**。海报的 abstract 是讲者自己写的叙事框架，会交代被压缩或砍掉的部分（常带 if time permits）；板书只记录实际讲到的地方。两者对照才知道哪段是「讲座没讲完」、哪段只是漏记——只读笔记会把「砍掉」和「没写」混为一谈。
- **概览型要求**（「大概讲了什么、不用很细」）的交付形态：主线一句话 → 4–5 站路线图（每站只写「被什么困难逼出 / 解决什么 / 通向哪」）→ 三句话记住 → 结尾一句「哪一站要展开」。按动机链排站，**不按笔记的节号顺序梳理**（按节号复述 = 又变成总结）。
- **必标两件事**：① 笔记覆盖到第几节（讲没讲完）；② 标题里的哪些词在正文只是名义上出现（如「范畴化」在讲座里只落成一个例子）。诚实标注比补齐更符合他的要求。
- 历史线索只在有把握时给粗线条（人名 + 世纪），精确年份不核就不写，宁可标「记忆，未核」。
- **他一旦说「讲点相关的数学史，像群论那时候一样」，就按六幕讲**（不变量论危机 → Frobenius 特征标/Schur 的中心化子 → Weyl 与物理 → Bruhat/Hecke 上 F_q → 量子群 → 范畴化）：已核实的时间线、原话、刊物卷页、以及「哪句引文归属不可靠」全在 `references/representation-theory-history.md`，**先读它，别重新调研**。讲法仍是三幕一停踢一次球，不一口气讲完。
- **他问「是不是最好等学完 X 再回头理解」时按三步答**：① 核 X 在他笔记里覆盖到哪（具体文件 + 节号）；② 核材料实际用到 X 的多少（通常远少于他以为——讲座只要最基本的双线性与结合性）；③ 把缺口分层：骨架层（现在就能拿，不需要前置）与细节层（需要课程不覆盖的外部件，给书名 + 章节）。**X 已学过就直说「不成立」，别顺着「等」**——「等前置」清单会变成永久搁置。
- **判断「等不等得到」要核课程边界**：群论课不会讲 $\mathfrak{S}_n$ 的不可约↔分拆（Specht 模）、$\mathrm{GL}_d$ 的最高权分类、对称函数环与表示环、量子群 ⇒ 这些缺口等课是等不到的，补课要外部书（Sagan《The Symmetric Group》GTM 203 的 Specht 模一章 → Macdonald / Stanley EC2 的对称函数 → Kassel 量子群）。
- **落盘**：讲座页末节写「掌握状态与补课路径」（可即刻掌握 / 课程不覆盖的缺口 / 补课顺序），按 vault 门禁（`check_notation` / `check_concept_sync` / `check_wikilinks`）跑绿后提交。
- **他说「太复杂了 / 一时讲不清楚就算了」= 一轮内收尾，不再推进**：只留 ①一句话骨架 ②一个以后触发的条件（学到 Specht 模 / 对称函数 / 表示论课时再回头），然后停。**不要用「那我换个角度讲」挽留，也不要把已排好的下一幕讲完**——他已经判断成本高于收益，继续讲是把 agent 的进度感当成他的需求。已查的史实与出处照常落盘（他不看也要存），但不铺开在对话里。
- **史线的 vault 落脚点**：`概念/表示论简史.md`（1890–1999 年表，逐条标出处；三处不可靠处：Gordan「神学」引文归属、双中心化子的措辞非 Schur 原文、$S_\infty$ 属现代框架）。再讲这条线先读它 ＋ `references/representation-theory-history.md`（技能内六幕讲稿），别重复调研。
