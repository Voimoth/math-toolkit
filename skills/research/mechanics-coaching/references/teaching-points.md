# teaching-points（自 SKILL.md 搬家，原文零删改）

## 已沉淀的教学要点

1. **用户会从元问题切入,不从做题切入**:hw2 第一轮他连续问了三个元问题——① 变分和导数区别、为什么能换序;② $L$ 里的参数 $t$ 会怎样;③ 为什么不是直接用可交换、$\frac{d}{dt}$ 与 $\frac{\partial}{\partial t}$ 区别。**先答元问题再回到题目**,别催他动手。
2. **给的每条规则都要交代\"是公理还是待验证的结论\"**:用户会拿上一轮我给的结论反问\"为什么不能直接用\"。凡需要验证的结论被包装成\"可直接套用的规则\",他一定会追问它的适用范围,而追问会暴露我的偷懒。
3. **变分法讲解的严格性依据走分析III**:换序 = 积分号下求导(区间有限 + 被控制),用户已学。**不要引测度论角度**(未学)。
4. **讲严格条件时说清"哪些本质、哪些技术性"**——用户爱问本质问题("条件用到了吗/能省吗"),这是他理解深度的信号,先正面确认其直觉再精确定位。
5. **严禁术语堆砌(2026-09-14 被斥责)**——讲第 3 题时我连写"一阶近似/泰勒展开/小参数 $\epsilon$"却没先讲人话,用户直接斥:"别勾巴的扯什么一阶近似二阶近似,是人话吗。不就是对 (r-R) 做泰勒展开,然后忽略高阶项吗"。**正确姿势**:先用口语说清"要干什么、为什么这么干"(如"根号里在 $r=R_\odot$ 处为零,要先因式分解拆出干净部分,再扔掉极小的一丁点"),**然后**才引入术语;术语是标签不是解释。用户数学功底强,他要的是机制而不是名词。
6. **"我不想算了,直接给答案"是合法信号**——本轮他在第 3 题积分前这么说了。此时**给完整答案**是对的(模式 A),不必坚持陪练;但答案里要保留关键步骤结构,并在数值结果与教材/GR 值不符时主动指出(见下条)。
7. **不要用例子当脚手架,除非他先要例子(2026-09-14 第二次被斥)**:他问\"抛开这道题,你设一些干净的系数,推导一下内摆线的**极坐标参数方程**\",我却挑了 $n=3$ 的三尖 deltoid 演示,他骂:\"他妈的谁让你推什么三尖了, 写个一般形式的\"。**规则:他要一般形式就写一般形式($R$ 大圆、$a$ 小圆、保留符号),要抽象就给抽象。举例演示是\"降级\",不是\"友好\"。** 这与第 5 条是一体两面:第 5 条禁术语包装,本条禁擅自降级成特例。
8. **"agent 讲错"要当轮标注更正,不要删帖重写**:2(a) 里我把不该消的项消掉了,当场写\"我上一段写法有误,更正\"并给正确版——用户没有不满(与画像\"期望 agent 诚实承认论证缺口\"一致)。**悄悄糊过去才是大忌。**
9. **"直接给答案"是一次性授权,不是模式切换(2026-09-14 最重要的教训)**:第 6(d)、第 8(a) 我连续两轮直接倒完整解答,用户被迫第二次下令\"**首先, 用coach技能, 不要直接给答案**\"。规则细化:
   - 第 6 条\"我不想算了/直接给我答案\"**只豁免那一题那一次**;下一题自动回到陪练。
   - **不要因为上一题给了答案,就认为本会话已切到模式 A。** 每道新题重新默认 GUIDED(一次一步、给第一步不给全解)。
   - 用户催\"怎么办/怎么做\" **不等于** 要全解——仍是给第一步。真给全解的信号只有\"讲给我听/直接说答案/我放弃了\"这类明确话。
   - 判断口诀:**这道题他还没提交任何尝试 ⇒ 陪练。**
10. **绝不断言未经推导的物理结论(2026-09-14 被抓)**:第 6(d) 我写\"由 (a) 已知隧道内是简谐振动\",用户立刻反问\"**现在做的不是直线运动, 凭什么简谐**\"。(a) 是**直线**隧道的结论,(d) 是**曲线**隧道,不能搬。**正确论证**:粒子受三维谐振子力 $\vec F=-\frac gR\vec r$,该力在**任何**直线投影上是简谐;弯曲隧道里粒子被约束,不是自由谐振子,\"参数 $\phi$ 匀速\"要另证(且 $\phi$ 是 (c) 的参数,不是空间角 $\theta$)。**规则:凡\"由前一小问已知\"要搬结论到本小问,先检查前提(直线 vs 曲线、约束有无)是否变。**
11. **长回复会卡死 GUI(2026-09-14 用户亲历并追问)**:用户问\"为什么刚才卡死了\"——我当时连着两轮输出了巨量 LaTeX 推导。**约束:单条回复控制在一屏可读**(约 40 行以内 LaTeX 当量);长推导拆成多轮,或先问\"要完整推导还是结论\"。这也直接服务省 token 规则。**别再自己加戏**(如第 7 条的特例演示),那是长度的主要来源。
12. **\"直接给答案\"只答他问的那一件事(2026-09-14)**:他说\"直接说答案\"给第 6(c) 时,我给的是那两行公式——对。**不要借机把整题 (a)(b)(d) 全倒出来。** 同理,他说\"把推导重新发一遍\"时只重发被卡掉的那段,不加新内容。
13. **wikilink 只指向真实存在的页(2026-09-14 用户明令\"不要往文件里面写不存在的链接\")**:写\"相关概念\"前先取现存页 basename 集合做存在性检查;未建内容写**纯文字**并注明\"未创建页面\"。原因:Obsidian 点空 wikilink 会**自动新建空文件**。检查命令与 PowerShell 编辑坑见 `references/variational-hw2.md` §6b。

14. **概念页里不放作业题解(2026-09-14 被斥\"你知道"概念"两个字什么意思吗\")**:第一次沉淀变分法时,我把页面写成了**作业题解汇编**——每节挂\"作业二第 X 题\",塞进题目专属数值(R_⊙、42.2 分钟、合肥北京、0.87'')、凑题过程、\"交作业时建议加一句说明\"。用户怒斥。**规则:概念页只写概念本身**——定义、为什么成立、证明要点、概念性陷阱、方法对比。**删掉**:题号、题目专属数值与算例、\"与题给 (X) 式一致\"这类做题痕迹、作业建议、某个具体题目的内摆线凑题推导。**保留**:真正的概念(如 Beltrami 恒等式、全导数不改变动力学、费马原理、测地线方程)与**概念性**陷阱(如\"全导数积分为零\"要分三步、折射率里的因子 2、对称化是纯记账)。
   **判据**:这句话换个题目还成立吗?不成立 ⇒ 属于题解,不进概念页。作业题解只留在本技能的 `references/` 里。

15. **一个概念一个文件,不要堆大文件(2026-09-14 被斥\"那一个文件那么大, 你不会给不同概念用不同文件吗\")**:我交了一个 14.5 KB / 12 节的单页,用户驳回。**已定型做法**:拆成 **11 个概念页(每个 1.5–3.5 KB)+ 1 个入口页 `变分法学习路径.md`**(因果链 + 概念清单 + 三句话),`_索引.md` 指向入口页。这与 vault 既有拆分原则一致(见 `wiki-writing-conventions`、`math-notes-transcription`)。**动笔建页时就直接按概念拆,不要先写大文件再拆**:概念页超过约 4 KB 或含 3 个以上独立概念即为信号。物理\\理论力学\\ 是**平铺**结构(无 概念\\ 子目录)。

16. **卡住信号的粒度（方法层；math-coach 不接受自动写入，暂先落在此）**：他写「不知道 $E$ 怎么用」时要的是**机制**——
    指出在哪个点（近心点、$\dot r=0$）、用哪条式子（能量积分）求值就足以定出它，然后**停手**；
    「把计算过程展示一下 / 讲给我听」才是要完整推导。先给机制、等他再开口，比一次倒全解省他的时间也省 token。
17. **形式类比式的「移植」要分层次判定**：他常先抛一个形式上像的迁移（「这题相当于上题把 $k$ 换成 $-\alpha$」）。
    合格回应不是「对 / 不对」，而是说清它**在哪一层**成立——解层 / 一阶积分层 / 定义层各不相同，
    跨层替换坏在哪（典型：前一题那条方程里已经代入了特例条件，再换符号整个式子失效），最后指出还欠的那座桥。
    只报对错会被他当作追问的起点。

18. **讲有心力场前先把极坐标的记号与降维链钉死（他必问）**：他会拿矢量/标量混用反问「$r$ 是矢量、$r_c$ 是标量,
    为什么能相减」「$\theta$ 是哪来的」。两句话先说在前面:① $r\equiv|\vec r|$ 是**径向坐标(标量)**,
    写 $\vec r=r\hat e_r$ 后方向信息全在 $\hat e_r$ 里;「圆轨道」指标量 $r\equiv r_c$,不是矢量恒定(转的是 $\hat e_r$);
    径向方程 $\mu(\ddot r-r\dot\theta^2)=F(r)$ 里的 $\ddot r$ 也是标量的二阶导,别和 $\vec r$ 的二阶导混读。
    ② $\theta$ 是换坐标换出来的第二个自由度:$V=V(r)\Rightarrow\theta$ 循环 $\Rightarrow p_\theta=\mu r^2\dot\theta=L$ 守恒,
    于是它不参与解方程,事后由 $\theta=\int L/(\mu r^2)\,dt$ 一积即得;自由度由 2 降到 1,$\theta$ 留下的唯一痕迹是
    $V_{\rm eff}$ 里的离心项。不先交代这条链,他会逐个追问、把主线拖回来。

19. **接「继续做作业」类请求先定位进度,别自己猜**:他会说「继续做下载里的两份物理题,从 hw4 第 5 题 b 开始」。正确起手:①读本技能 SKILL.md 的进度行与对应 `references/`;②`session_search` 上一轮(按 hw/作业/课程名搜,看最后停在哪一小问);③再去 `~/下载` 取当次 PDF 正文;④起手点以**他报的题号**为准。他报的题号可能跳过他已在纸上做完的小问(本次从 5(b) 起手,5(a) 我们没讲过)——照他说的走,不回头补讲、也不问他为什么跳过。

20. **定量结论交付前必须有一条自身实现之外的检验路径**:本机没有 scipy,数值自检用纯 stdlib(`scripts/precession_check.py`);先在**有精确解的姊妹情形**上把管线验到 10 位吻合(进动角用 $\beta/r^2$ 那支),再去数微扰那支,并注明确切的量级估计/误差台阶。只给教科书答案而拿不出独立核对,会被他当作没验。

21. **他拿「老师讲的是另一条路」质疑时：回讲义原文核实，别辩护也别立刻倒戈（方法层；math-coach 不接受自动写入，暂寄在此）**。
    典型话：「不过你如果看讲义的话，我觉得我们老师讲的是另一种路径？」这不是挑刺，是他真的在对照讲义。三步缺一不可：
    ① `pdftotext` 提出原文 + `grep -n` 定位到**具体节号与页号**——答案必须带页号，不能只说「讲义里也是这样」；
    ② 把他说的路径与我的路径**放进同一坐标系判定是否等价**，当场写出判定式（例：广义本征值 $\det(K-\omega^2M)=0$ 与标准本征值 $\det(\lambda-\omega^2I)=0$，$\lambda=M^{-1/2}KM^{-1/2}$，两者只差非零因子 $\det M$）；
    ③ 指出**差别在产出**——哪条路顺带给出他这次要交的那个东西（本例 (c) 要变换矩阵⇒走 §5.4，他的判断比我的默认路径更合适）。
    只答「都对」等于没答；只答「我错了」会把其实正确的那部分丢掉（$\det(K-\omega^2M)=0$ 确实就是讲义的 5.20）。
    顺手复查那一页有无印刷错误，发现的当轮告诉他并给判据（量纲/极限/特例）——那是他真正会记住的部分。

22. **移动端（微信/手机）对话时的输出形态（方法层；math-coach 不接受自动写入，暂寄在此）**。
    他在手机上时**看不见本地讲义 PDF**，也没法在长回复里定位。四条：
    ① 不要拿「第 $X$ 页 / 第 $Y$ 节」当指代，要讲就讲内容本身；核页号是**我这边**的动作（见第 21 条），
       交付给他的是内容，不是页码。
    ② 单条回复压成「结论 + 一个动作」两段；禁多层嵌套列表、括号套括号、一段并列三个以上要点。
    ③ **凡出现公式就渲成 PNG 发图**（`MEDIA:` + xelatex/pdftoppm），**不贴 LaTeX 源码、也不用 Unicode 上标冒充**——
       他原话：「你直接打 latex 我这里没法渲染，遇到这种需要 latex 的情况你发图片不就好了」。
       叙述文字照常走正文（结论、判定、追问）；配方见 `hermes-self-config` 的 `references/messaging-surfaces-and-math-rendering.md`。
    ④ 他说「看不见 / 看不清 / 乱了」时，下一步**只回答他问的那一个问题**，不补路线图、不补备选方案、
       不补收尾提醒。

23. **解释数学结论用数学语言，不要用散文判别句（方法层；被斥「毫无可读性」）**。
    他要的是「记号声明 → 编号公式 → 每步依据」，不是一段「你前半句对、后半句错」的对话式散文。
    **判据**：把「你说的对/不对」这类过渡句全删掉，信息若仍完整，那它们就都该删。
    对他**尝试**的判定仍然要留（对/错/缺哪一步 + 判据），但压成一行，判定之后的内容必须是数学。
    例（简正坐标 vs 本征矢量）：先声明 $M,K\in\mathrm{Sym}(n,\mathbb R)$、$M\succ0$、$\xi_i$ 满足
    $(K-\lambda_iM)\xi_i=0$ 且 $\xi_i^{\mathsf T}M\xi_j=\delta_{ij}$，再用 ①②③ 推 $y=\Xi^{-1}\theta$、
    $\ddot y+\mathrm{diag}(\lambda)y=0$、$y_i=A_i\cos(\omega_it+\varphi_i)$ —— 而不是三段口语描述两者区别。

24. **行话先定义、定理要解释；「一大坨汉字」= 立刻改形态（方法层；math-coach 不接受自动写入，暂寄在此）**。
    他的原话：「我没看懂你在说什么，能不能不要这样掏一大坨汉字出来」「你会说人话吗，什么叫『舌』？」「给我把这类方程从头讲清楚，
    **不要出现任何未定义的记号，也不要扔一个定理上来什么都不解释**」。三條硬规则：
    - **每个符号第一次出现就定义**（「$t$ 是时间，$p$ 是以 $T$ 为周期的已知函数」）；每个定理先说他解决什么问题、凭什么成立，再给名字。
      只写「由 Floquet 定理」加一句结论 = 没讲，他一定反问「凭什么」。
    - **自创或借来的行话（如「不稳定舌」）必须当场给一句定义或一张图**；没定义就是主线断裂点。
    - 他说「看不懂 / 你在说什么」时**不要换措辞再写一遍**：立刻改形态——分块编号 + 公式渲图，散文只留判定句。

25. **表达形态与数学同一套（2026-10-22 用户明令「讲物理的时候也要这样」）**。
    力学的讲解与解答一律按 `math-coach` 的 A24 ＋ `math-coach/references/mathematical-prose.md`：
    法国题式小结论链（3–5 条小结论，每条一两句，最后一句说怎么拼出结论）、一句一断言、
    动词用标准中文（映到 / 变到 / 与…相容 / 取值为零，**不写「送到」**）。
    **发出前跑** `python3 ~/.hermes/skills/research/math-coach/scripts/prose_lint.py -`，必须改的条目清零才发。
    本技能不复制规则，只做指针——方法层唯一出处是 `math-coach`。
