# PDF Problem Search(本地数学资料检索)

在用户的本地 PDF 数学库中定位数学定理、习题、问题陈述所在的文件和页码。

## 触发

- "这个定理/题目在哪个 PDF?"、"pdf-problem-search"
- 需要找某数学结论在本地资料的出处(教材、讲义、习题集)
- OCR 损坏的数学语句想定位原始出处

## 环境事实

- **PDF 库**: `/mnt/e/书籍/`(含分析/代数/几何/数论/组合/竞赛等,含 pika开源资源 子目录)
- **PDF 提取管线**: 系统 poppler —— `pdftotext -layout in.pdf out.txt`(中文正常);扫描版走 pdftoppm + tesseract。用法:
  ```
  pdftotext -layout "<输入.pdf>" "<输出.txt>"
  ```
- 注意:提取大 PDF(100 页+)慢且费 token——**先用文件名/目录预筛,再精提取**。

## 工作流

1. **预筛(必做,省时省 token)**:
   - 用 `search_files(target='files')` 按文件名/目录名匹配候选 PDF(如找"等周不等式"→ 看分析/几何相关目录)
   - 用 `search_files(target='content')` 只搜已知文本化的 .txt 提取件(如果已有)
2. **精提取**:对 2-3 个最可能候选 PDF 用 `pdftotext` 提取(大文件分段 `-f/-l`),搜索目标语句
3. **验证**:定位页码,报告:
   - source(文件路径)
   - location(PDF 页 / 打印页)
   - match type(精确/部分/名称匹配)
   - why(为什么认为这是出处)
   - confidence(高/中/低)
   - gap(未覆盖的搜索盲区)
4. 若找不到,诚实报告"库中可能没有",建议补充来源。

## 查询归一化（先做，再搜）

- **不许提前放宽硬概念**：`Borel 可测` vs `Lebesgue 可测`、`右连续` vs `连续`、`下半连续` vs `上半连续`、
  `单调函数` 与「只提到单调收敛的页」是不同对象。命中**更弱或不同**的命题 ⇒ 不是精确命中，只能标 near-exact / 旁证。
- **别名集保持小**（4–6 条）：原查询 + 一条 ASCII/数学写法 + 中文查询加一条英文写法 + 1–4 个领域别名；
  不要加 `n`、`x`、`sum`、`R` 这种到处都有的裸符号。
- **定理名要和它的算子/族粘在一起**：`Young 不等式` + `卷积`，不要裸 `Young`。
- **公式转一句自然语言**：`∑_{n≤x} 1/φ(n)` → 「欧拉函数倒数的和」；`x²−6y²=1` → 「Pell 方程整数解」。
- **OCR 容错**：中文可能乱码；题号可能是 `27.` 或 `2 7 .`；`f` 可能被识别成 `/`；`->` 可能丢失。
  **归一化只用于召回，判定必须以原文页为准。**

## 验证规则（不看 top-1，至少看 top-3）

升权：目标**编号题面 / 编号定理陈述就在这一页**；关键概念出现在**同一个局部陈述**里（不是同页散落）。
降权：章节总览页、只列 `习题 21–29` 的页、提示页/解答页、只提供证明零件的页、丢掉或弱化硬概念的邻近变体。

- 只有当硬概念都在局部证据窗口里，才能报`精确命中`。
- 报告尽量给 **1-based PDF 页码**（打印页码可选，不能替代它），并注明提取状态。
- OCR 损坏到无法直接核对时，明说并降置信度。
- 若命中来自**未索引**的 PDF（走了直接提取兜底），在 `gap` 里写明。

## 空结果怎么报（重要）

只能说「在**已检查、当前已索引/已提取**的范围内没找到」，**不能**说「本地没有这个定理」。
未索引目录、扫描件无文本层、提取失败或空提取都属于**覆盖状态**，不是「不相关」，也不是「不存在」。

## 失败 → 当轮冻结成回归用例

一次失败（尤其他纠正过的）**在同一轮里**就记成回归用例（查询 + 期望出处 + 失败原因），别攒着。
改进时先定位失败在哪一层：① 语料覆盖/未索引 ② 查询归一化 ③ 页面理解（角色/局部陈述）④ 排序打分；
优先做**可复用**的修（加特征、改别名规则、加降权规则），不要为一个用例打特例补丁。
原项目这套方法论（含「别让 SKILL.md 变成历史错误目录」「重构触发条件」）见
`/mnt/e/pika_math_learning_toolkit-2.1.5/payload/pdf-problem-search/references/improvement-strategy.md`（英文）。

## 陷阱

- 中文 PDF 用 `pdftotext`(系统 poppler,中文正常);扫描版才需 OCR
- 大 PDF 不要整本提取,先按页范围提取(`pdftotext -f <起页> -l <止页>`)
- 维基百科被墙,无法在线核对——以本地资料为准
- 定理可能在多本书出现,报告最权威/最相关的一处即可,不必穷举
