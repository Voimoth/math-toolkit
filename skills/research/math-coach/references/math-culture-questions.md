# 数学思想史与学派类提问

触发：他读完一本书的一段（Klein、Stillwell、Hardy、Gowers 一类）后问「作者为什么这么写」「这个观点有点怪」「两个学派差在哪」。这既不是数学辅导也不是情绪陪伴：给历史动机与判据，不改写书的内容，也不劝他喜欢某个学派。

## 1. 交付形态

- 三层分开：概念上的先后 / 术语命名的先后 / **作者的读者是谁**。他的「怪」感多数来自第三层没被点明。
- 主判据：先问作者的读者是谁。读者决定取舍，取舍决定体例。Klein 写给中学教师（要教、要直观），Bourbaki 写给未来的研究者（要不重复、不留漏洞）——同一个「结构」取向，两种体例。
- 不评价学派高下、不做「某纲领是失败的」这类简化。

## 2. 核实路径（省成本的那条）

- 中译本**卷首导读**常把作者立场概括成完整一段，比正文可靠且便宜：`pdftoppm -f 3 -l 14 -r 150 -png` + `tesseract -l chi_sim`，十几页即可同时拿到目录与立场。
- 交付时**必须声明**：引文来自导读，正文未逐页核对。不要把导读的转述说成「他书里说」。
- 扫描版正文要 OCR 全文，代价远高于导读；先试导读，不够再扩。

## 3. 已核实的卡（Klein，《高观点下的初等数学》第一卷）

- 反对「公理可以随心所欲地选取，只要彼此相容」；主张公理不能脱离直觉、不能排除人对客观事物的认识。
- 反对按公理体系教学：首先不符合学生的认识规律，逻辑不是教学中唯一的指导原则。
- **树根隐喻（他的核心论据）**：树长大时躯干枝叶向上、根同时向下，故既无终点也无最初的始点，从而没有进行教学的绝对基础——公理不是地基，是与枝叶共同生长的产物。原文见中译本卷首导读（吴大任）。
- 为什么把逻辑、认识论、心理学写在一章：读者是教师，「数怎么进入学生头脑」是发生学问题；且 1900 前后「数的概念」正是论战中心（Dedekind 1888、Frege 1884、Peano 1889、Hilbert 1899）。今天的「怪」是 20 世纪后这三者分家造成的。

## 4. 已核实的卡（Klein 与 Bourbaki）

- 不是对立：Klein 的 Erlangen 纲领（几何 = 变换群下的不变量理论）本身就是结构思想；差别在尺度——他用结构组织一个领域，Bourbaki 用结构重建全部数学。
- Bourbaki 能那么抽象的技术核心：三种母结构（代数、拓扑、序）＋一条操作原则「同一个证明只证一次，所有特例免费」，即 §13 的「真类比共享证明」被制度化。抽象是省重复的代价，不是求深的姿态。
- 历史动机是工程性的：一战打空法国中间代，1934 年 Cartan/Dieudonné/Weil 要替换 Goursat 那套老分析教材、追 van der Waerden 1930。属工程任务，不是审美偏好。
- 失败处：母结构只有三种，装不下层与概型；未吸收范畴论（最终取代其结构语言的是 Eilenberg–Mac Lane）；教材层面去直观后难教。

## 5. 边界

- 他说「这书写得怪」时先分「作者的问题」与「体例的问题」，后者占多数。
- 史实归属他会在意：未核实就说未核实，不把背景判断写成书里的原话。
- 这类提问不落 vault 概念页（不是课程概念），也不进 wiki；只在对话里交付。
